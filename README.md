# ScriptBase
## Übersicht
- **Siril_autoEverything/**: Leitfaden und Aufgabenbasis zur Automatisierung eines Siril-Skripts für die vollautomatische Verarbeitung von Deep-Sky-Bildern ab einem gestackten FITS. Enthält Prozessschritte, Qualitätsmetriken, eine Aufgabenliste (`task.md`) sowie `REFERENCE_Naztronomy.md` als Funktions- und Architektur-Referenz zum Beispelskript „Naztronomy - OSC Image Preprocessor“.
Weitere Inhalte werden hier ergänzt, sobald zusätzliche Projekte hinzukommen.
